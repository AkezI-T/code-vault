# Control and motion algorithms

[简体中文](README.md) | English

Chip-agnostic control and motion algorithm modules that run on any MCU with integer arithmetic and depend on no specific peripheral.

## Modules

| Module | Language | Responsibility |
| --- | --- | --- |
| [pid-controller](pid-controller/README.en.md) | C | Fixed-point PID: proportional, integral, measurement derivative, deadzone, clamping, low-pass and direction |

See [docs/architecture.md](../docs/architecture.md) for file placement and [docs/module-template.md](../docs/module-template.md) for the module documentation template.
