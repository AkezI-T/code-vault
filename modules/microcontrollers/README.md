# 单片机模块

存放可复用的单片机固件模块，例如外设驱动、通信协议和控制算法。按芯片类别存放在 `<chip>/<module-name>/` 下，例如 `esp32-s3`、`mspm0g3507`、`k230`。每个模块自行管理源码和依赖。

文件和文件夹使用英文命名。模块名称描述功能，不带品牌名；适用的通信方式写入名称，例如巡线模块命名为 `i2c-line-sensor`。名称中的通信方式必须与实际实现一致。

每个 `<module-name>/` 根目录必须包含简体中文 `README.md` 使用说明，按[架构规则](../../docs/architecture.md)和[模块模板](../../docs/module-template.md)写清支持的芯片与框架、接线与配置、完整调用示例，以及每个公开 API 的签名、参数、返回值、错误和调用约束。

电脑端使用的开发工具放在[单片机工具目录](../../tools/microcontrollers/README.md)。
