# Microcontroller tools

[简体中文](README.md) | English

Store host-side microcontroller development tools, such as flashing helpers, serial data processors, firmware packagers, and debugging utilities. Each tool uses an English directory name and lives under `<tool-name>/`.

Each tool documents its runtime, dependencies, supported devices, commands, and connection requirements for hardware operations.

Firmware code running on microcontrollers lives in [modules/microcontrollers/](../../modules/microcontrollers/README.en.md).
